The previous Fastify backend was removed during the reset. This standalone documentation server preserves that reset. The frontend continues to use its mock flow.

Local services

  • Frontend: http://localhost:3000
  • Backend documentation: http://localhost:3001/docs
  • Documentation server health: /health

From the project's backend folder, run npm run dev. Node.js 22 or later is required. No dependency installation, environment file, or API keys are needed for this docs server. It always uses port 3001.

Planned Next.js API routes

These routes are planned for Step 6 of the setup guide. They are not available on this documentation server.

  • src/app/api/suggest-stops/route.ts — stop suggestions
  • src/app/api/plan-trip/route.ts — trip planning
  • src/lib/gemini.ts and src/lib/maps.ts — provider helpers

Future Next.js handlers belong to the existing app. Their request and response shapes must be coordinated with the frontend before integration.

Preserved project references
