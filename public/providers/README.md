# Provider assets

Local brand artwork used only to identify the adjacent rideshare provider. Brand
and trademark rights remain with their owners; these files are not an endorsement.

- `uber.jpg`: Uber Technologies, Inc.'s app artwork from its official Apple App
  Store listing, https://apps.apple.com/app/id368677368 (retrieved via Apple's
  lookup API on 2026-10-11).
- `lyft.png`: Unmodified `Lyft_Logo_Pink_RGB.png` from Lyft's official digital
  logo pack, https://www.lyft.com/press/media-kit (retrieved 2026-10-11).
- `waymo.png`: Unmodified `Waymo_Secondary_RGB.png` from the official Waymo
  secondary logo pack, https://waymo.com/media-resources/ (retrieved 2026-10-11).
  Source: Waymo. Waymo provides these assets for press and educational purposes;
  commercial use requires contacting Waymo as stated on its media resource page.

The original colors and proportions are retained. Images have empty alternative
text because the adjacent provider heading already names the brand.
